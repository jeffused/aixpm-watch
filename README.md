# AIxPM Watch

Veille AI × Project Management — articles courts en français sur l'usage de l'IA dans le conseil et la gestion de projet.

Live: [jeffused.github.io/aixpm-watch](https://jeffused.github.io/aixpm-watch/)

## Stack

- [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) (blog plugin)
- Auto-déploiement via GitHub Actions sur push vers `main`

## Local preview

```bash
pip install mkdocs-material
mkdocs serve
```

## Authoring

Articles vivent dans `docs/posts/YYYY-MM-DD-slug.md`. Format et taxonomie : voir le projet privé AIxPM (ce repo n'héberge que la sortie publiée).
