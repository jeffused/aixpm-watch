# Agent Claude sur mesure : du formulaire de demande au plan projet complet, 80 % d'effort en moins

Un PM décrit un agent personnalisé (projet Claude, doublé d'un agent Copilot en test) nourri d'une dizaine de PDF documentant l'outil PM de l'entreprise, la configuration de l'espace de travail et le vocabulaire maison, plus un tableur des équipes et du parc logiciel. À partir du formulaire de demande projet rempli par le demandeur et du transcript de la réunion de lancement, l'agent génère le projet entier — tâches, descriptions, estimations d'effort, dates proposées, métadonnées — importé ensuite en CSV : « saves me like 80% of the effort ». La condition explicite : un plan enterprise pour les données d'entreprise, et une base de connaissance maintenue — « you do it in any default AI chat bot and you will get nonsense ».

Le fil documente une deuxième mécanique : les serveurs MCP des outils existants (Jira, Confluence, Miro) branchés sur Claude Code pour produire des rapports que les systèmes sources ne savent pas générer, détecter et corriger en masse les incohérences de données Jira, et rédiger la documentation projet — des travaux de concentration désormais casés « dans les 5 minutes entre deux réunions ».

Deux patterns convergents : la valeur ne vient pas de l'outil brut, mais du contexte d'entreprise structuré qu'on lui donne.
