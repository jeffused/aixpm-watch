# Notes de réunion : du notetaker acheté au pipeline Claude avec validation humaine

Un PM d'une entreprise de 60 personnes cherche un notetaker IA qui fasse mieux que « déposer un lien de transcript dans un champ commentaire » : il veut des actions structurées dans ClickUp et des synthèses classées dans Notion. La réponse la plus utile du fil ne recommande aucun outil — elle décrit un pipeline maison.

Le praticien fait tourner une skill Claude qui récupère le transcript Zoom, le recoupe avec sa base de connaissances pour identifier noms et sujets, produit les notes dans son format, puis **s'arrête pour validation humaine** avant d'exécuter la suite : notes archivées dans Airtable, actions créées et assignées dans le registre d'actions, copie dans un coffre Obsidian, brouillon de récap Slack — qu'il envoie lui-même, avec des versions différentes selon l'audience. Traité en lot en fin de journée : 20 à 30 minutes pour 6 à 8 réunions. Détail décisif : « Claude, Airtable, Zoom, Slack et leurs connecteurs sont tous approuvés par mon entreprise ».

Un second PM décrit le même schéma (Fellow pour les notes, un agent Claude Code qui relit le transcript brut et regroupe les actions par responsable, envoyées par e-mail « parce que les responsables ne mettront pas ClickUp à jour »). Le signal : les PM avancés n'achètent plus l'intégration, ils l'orchestrent — en gardant la main sur ce qui part vers l'équipe.
