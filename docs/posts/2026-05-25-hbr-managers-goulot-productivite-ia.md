# « Toutes les 30 minutes, quelqu'un crée quelque chose que je dois examiner » : le manager devient le goulot

Dans Harvard Business Review du 25 mai 2026, Liz Fosslien et Mollie West Duffy ouvrent leur analyse par la phrase d'un manager qui circule beaucoup en ce moment : *« Every 30 minutes, someone creates something I have to look at. »* La thèse de l'article n'est plus que l'IA va remplacer des collaborateurs ; c'est que la première vague d'augmentation IA expose un goulot que personne n'avait préparé — **le manager intermédiaire**. Quand chaque membre de l'équipe accélère individuellement avec un assistant IA, le volume de production passant par la file d'attente de validation managériale double, triple, sans que les méthodes de revue, de feedback et de coordination managériales n'aient évolué.

Le diagnostic prolonge directement une analyse Les Echos déjà capitalisée dans la veille AIxPM : « La clé n'est pas dans les serveurs, elle est dans les milliers de cadres intermédiaires qui font le lien entre la stratégie et la réalité. » Sauf que la version HBR pousse plus loin : le cadre intermédiaire n'est pas seulement le maillon manquant pour transformer la stratégie en exécution, il est aussi le maillon qui ne tient plus quand l'exécution s'accélère sans révision de son outillage managérial. Les indicateurs implicites — combien de versions de slides un manager peut polir par jour, combien d'arbitrages stratégiques il peut rendre par semaine — atteignent une saturation qui n'apparaît dans aucun tableau de bord IA officiel.

Pour un comité de direction qui pilote un programme IA, la conclusion est inconfortable. Les outils ont été distribués, les usages individuels accélèrent, les chiffres d'adoption sont bons. Mais si le rôle managérial n'est pas explicitement redessiné — *comment* on revoit, *comment* on donne du feedback, *comment* on coordonne dans une équipe où chaque membre génère désormais en heures ce qu'il rendait en jours — alors le programme produit mécaniquement un goulot supérieur, douloureux pour les managers et coûteux pour l'organisation. Le redesign n'est pas un sujet de RH-confort. C'est un livrable de programme.
